## 🐛 已知问题排查

### 问题 1: Show Rate 未达到预期（<20%）

**可能原因**:
1. 云端配置的间隔时间过长
2. 缓存池补充不及时
3. 订阅用户占比过高

**排查步骤**:
```bash
# 1. 检查云端配置
adb logcat | grep "getNativeIntervalTime"

# 2. 检查缓存池状态
adb logcat | grep "getCacheSize"

# 3. 检查订阅状态
adb logcat | grep "User is subscribed"
```

**解决方案**:
- 云端将间隔时间设置为 300000（5分钟）
- 增加缓存池大小到 5
- 确认订阅检查逻辑正确

---

### 问题 2: 缓存池经常为空

**可能原因**:
1. 广告加载失败率高
2. 补充逻辑未触发
3. AdMob 限流

**排查步骤**:
```bash
# 检查加载失败日志
adb logcat | grep "❌ Failed to load"

# 检查补充逻辑
adb logcat | grep "📦 Cache low, replenishing"
```

**解决方案**:
- 检查 AdMob 广告单元ID配置
- 确认网络连接正常
- 检查 AdMob 账号是否被限制

---

### 问题 3: 崩溃率上升

**可能原因**:
1. Activity 生命周期问题
2. NativeAd 对象使用错误
3. 并发访问缓存池

**排查步骤**:
```bash
# 查看崩溃日志
adb logcat | grep -E "FATAL|AndroidRuntime"
```

**解决方案**:
- 确保所有 Activity 检查都使用 `isValid()`
- NativeAd 对象只使用一次
- 缓存池访问添加同步锁
