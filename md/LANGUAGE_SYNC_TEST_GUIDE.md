# 🧪 语言同步测试指南

**测试目标：** 验证经文翻译和注释语言是否与应用语言同步

---

## 🚀 快速测试（5分钟）

### 测试 1：印尼语同步测试

```bash
# 1. 安装最新版本
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 2. 启动日志监控
adb logcat | grep -E "TranslUtils|📱|🌐"
```

#### 在设备上操作：

1. **设置语言为印尼语**
   - 打开设置 → 语言 → 选择 "Bahasa Indonesia"

2. **打开任意古兰经章节**
   - 主页 → 古兰经 → 打开 Surah 1 (Al-Fatihah)

3. **检查翻译**
   - 阿拉伯语经文下方应显示**印尼语翻译**
   - 预期：Kompleks Al Quran Raja Fahd 版本

4. **检查注释**
   - 点击任意经文 → 查看 Tafsir
   - 预期：显示**印尼语注释**

#### ✅ 预期日志输出：

```
TranslUtils: 📱 Using app language from settings: id
TranslUtils: 🌐 App language: id (from SPAppConfigs)
TranslUtils: 🌐 Auto-selected translation: Indonesian (Kompleks Al Quran)
```

---

### 测试 2：英语同步测试

#### 在设备上操作：

1. **设置语言为英语**
   - 设置 → 语言 → 选择 "English"

2. **打开任意古兰经章节**
   - 主页 → Quran → Open Surah 1 (Al-Fatihah)

3. **检查翻译**
   - 阿拉伯语经文下方应显示**英语翻译**
   - 预期：Sahih International 版本

#### ✅ 预期日志输出：

```
TranslUtils: 📱 Using app language from settings: en
TranslUtils: 🌐 App language: en (from SPAppConfigs)
TranslUtils: 🌐 Auto-selected translation: English (Sahih International)
```
