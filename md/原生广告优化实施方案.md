# 原生广告优化实施方案

## 📋 目标

将原生广告 Show Rate 从 **0.9%** 提升到 **30-40%**，提升 **30-40 倍**！

---

## 🎯 三大优化方向

### 方向 A: 统一化（Unification）⭐⭐⭐⭐⭐

**目标**: 废弃分散的加载逻辑，统一使用 `NativeAdManager` 进行全局预加载和缓存

**当前问题**:
- Onboarding 使用 `NativeAdManager`
- Quiz 使用 `AdFactory.adsCache`
- 两套系统各自为政，缓存无法共享

**解决方案**: 所有原生广告都通过 `NativeAdManager` 管理

---

### 方向 B: 放宽拦截策略 ⭐⭐⭐⭐⭐

**目标**: 将 `NativeAdTimeUtil` 的拦截改为按场景（Tag）区分，并将时间间隔缩短到 5-10 分钟

**当前问题**:
- 全局时间拦截（可能 24 小时）
- 不区分场景，一刀切
- 导致 90-99% 的展示机会被浪费

**解决方案**: 按场景（Tag）区分，不同场景独立计时

---

### 方向 C: 预加载优先 ⭐⭐⭐⭐⭐

**目标**: 坚持"先有缓存再展示，展示后立即补充缓存"的策略，消除异步加载导致的"人走茶凉"现象

**当前问题**:
- 缓存为空时异步加载（1-3秒）
- 用户在加载期间离开页面
- 广告加载成功但无法展示

**解决方案**: 
1. 提升缓存池大小（1 → 3）
2. 消费后立即补充
3. 展示前必须有缓存，无缓存则不展示

---

### A1. 升级 NativeAdManager 支持多缓存

**文件**: `adlib/src/main/java/com/quranaudio/common/ad/NativeAdManager.kt`

**关键改动**:

```kotlin
class NativeAdManager private constructor() {
    
    companion object {
        private const val TAG = "NativeAdManager"
        private const val CACHE_POOL_SIZE = 3  // ✅ 从 1 提升到 3
    }
    
    // ✅ 改为缓存池
    private val cachedNativeAds = mutableListOf<NativeAd>()
    private val loadingCallbacks = mutableListOf<(NativeAd?) -> Unit>()
    private var isLoading = false
    
    /**
     * Get a cached native ad (FIFO).
     * Immediately triggers loadNewAd() if pool drops below threshold.
     */
    fun getCachedAd(activity: Activity): NativeAd? {
        // Check subscription
        if (SubscriptionChecker.isUserSubscribed(activity)) {
            Log.d(TAG, "🎁 User is subscribed, no native ad")
            return null
        }
        
        // Get from pool
        val ad = cachedNativeAds.removeFirstOrNull()
        if (ad == null) {
            Log.d(TAG, "⚠️ No cached native ad available")
            // Try to load for next time
            loadNewAd()
            return null
        }
        
        Log.d(TAG, "📺 Returning cached native ad (${cachedNativeAds.size} remaining)")
        
        // ✅ Immediately replenish if below threshold
        if (cachedNativeAds.size < 2) {  // Keep at least 2 in pool
            loadNewAd()
        }
        
        return ad
    }
    
    /**
     * Load a new native ad into the pool.
     */
    fun loadNewAd() {
        val context = appContext ?: return
        
        // Check if pool is full
        if (cachedNativeAds.size >= CACHE_POOL_SIZE) {
            Log.d(TAG, "✅ Cache pool is full (${cachedNativeAds.size}/$CACHE_POOL_SIZE)")
            return
        }
        
        if (isLoading) {
            Log.d(TAG, "⚠️ Ad is already loading, skipping duplicate")
            return
        }
        
        if (SubscriptionChecker.isUserSubscribed(context)) {
            Log.d(TAG, "🎁 User is subscribed, skipping load")
            return
        }
        
        isLoading = true
        Log.d(TAG, "🔄 Loading new native ad (${cachedNativeAds.size}/$CACHE_POOL_SIZE)")
        
        val adLoader = AdLoader.Builder(context, adUnitId)
            .forNativeAd { nativeAd ->
                Log.d(TAG, "✅ Native ad loaded successfully")
                cachedNativeAds.add(nativeAd)
                isLoading = false
                
                // Notify pending callbacks
                notifyPendingCallbacks(nativeAd)
                
                // ✅ Continue loading if pool not full
                if (cachedNativeAds.size < CACHE_POOL_SIZE) {
                    loadNewAd()
                }
            }
            .withAdListener(object : AdListener() {
                override fun onAdFailedToLoad(loadAdError: LoadAdError) {
                    Log.e(TAG, "❌ Failed to load: ${loadAdError.message}")
                    isLoading = false
                    notifyPendingCallbacks(null)
                    
                    // ✅ Retry after delay if pool is empty
                    if (cachedNativeAds.isEmpty()) {
                        Handler(Looper.getMainLooper()).postDelayed({
                            loadNewAd()
                        }, 30000)  // Retry after 30s
                    }
                }
            })
            .withNativeAdOptions(
                NativeAdOptions.Builder()
                    .setRequestCustomMuteThisAd(true)
                    .build()
            )
            .build()
        
        adLoader.loadAd(AdRequest.Builder().build())
    }
    
    /**
     * Load ad with callback (for immediate use).
     */
    fun loadAdWithCallback(activity: Activity, callback: (NativeAd?) -> Unit) {
        if (SubscriptionChecker.isUserSubscribed(activity)) {
            callback(null)
            return
        }
        
        // ✅ If cache available, return immediately
        if (cachedNativeAds.isNotEmpty()) {
            val ad = cachedNativeAds.removeFirstOrNull()
            Log.d(TAG, "✅ Returning cached ad immediately (${cachedNativeAds.size} remaining)")
            
            // Replenish pool
            if (cachedNativeAds.size < 2) {
                loadNewAd()
            }
            
            callback(ad)
            return
        }
        
        // ✅ No cache, add to pending and try load
        loadingCallbacks.add(callback)
        
        if (!isLoading) {
            Log.d(TAG, "🔄 Starting dynamic load for callback")
            loadNewAd()
        } else {
            Log.d(TAG, "⏳ Ad loading, callback queued")
        }
    }
    
    private fun notifyPendingCallbacks(nativeAd: NativeAd?) {
        if (loadingCallbacks.isNotEmpty()) {
            Log.d(TAG, "📢 Notifying ${loadingCallbacks.size} pending callbacks")
            loadingCallbacks.forEach { callback ->
                try {
                    callback(nativeAd)
                } catch (e: Exception) {
                    Log.e(TAG, "❌ Callback error: ${e.message}", e)
                }
            }
            loadingCallbacks.clear()
        }
    }
    
    /**
     * Check if cache is available.
     */
    fun hasCachedAd(context: Context): Boolean {
        if (SubscriptionChecker.isUserSubscribed(context)) {
            return false
        }
        return cachedNativeAds.isNotEmpty()
    }
}
```

**优点**:
- ✅ 缓存池大小从 1 提升到 3
- ✅ FIFO 机制，避免广告过期
- ✅ 自动补充，始终保持 2+ 缓存
- ✅ 加载失败自动重试

import android.app.Activity
import android.content.Context
import android.util.AttributeSet
import android.util.Log

import android.view.View

import com.quran.quranaudio.quiz.databinding.LayoutAdNativeSmallWrapperBinding

/**
 * ✅ 统一使用 NativeAdManager 的原生广告 View
 * 
 * 优化：
 * 1. 不再使用 AdFactory，统一使用 NativeAdManager
 * 2. 优化时间间隔拦截，按场景区分
 * 3. 只展示已缓存的广告，不做异步加载
 */
class AdNativeSmallWrapperView : LinearLayout {
    private val TAG = "NativeAdView"
    val binding = LayoutAdNativeSmallWrapperBinding.inflate(
        LayoutInflater.from(context), this, true
    )

    var isShowAd = false
    var isLoadAd = true
    var defaultMarginTop = -1f
    var defaultMarginBottom = -1f
    var adTag = ""

    constructor(context: Context) : this(context, null)
    constructor(context: Context, attrs: AttributeSet?) : this(context, attrs, 0)
    constructor(context: Context, attrs: AttributeSet?, defStyleAttr: Int) : super(
        context, attrs, defStyleAttr
    ) {
        // 初始化逻辑保持不变
        attrs?.let {
            val ob = context.obtainStyledAttributes(it, R.styleable.AdNativeSmallWrapperView)
            isShowAd = ob.getBoolean(R.styleable.AdNativeSmallWrapperView_default_show, false)
            isLoadAd = ob.getBoolean(R.styleable.AdNativeSmallWrapperView_default_load, true)
            defaultMarginTop = ob.getDimension(R.styleable.AdNativeSmallWrapperView_default_margin_top, -1f)
            defaultMarginBottom = ob.getDimension(R.styleable.AdNativeSmallWrapperView_default_margin_bottom, -1f)
            ob.recycle()
        }
        
        if (defaultMarginTop == -1f) {
            defaultMarginTop = resources.getDimension(R.dimen.dp_20)
        }
        
        (binding.root.layoutParams as LayoutParams).apply {
            val customMarginBottom = if (defaultMarginBottom == -1f) marginBottom else defaultMarginBottom
            setMargins(marginStart, defaultMarginTop.toInt(), marginEnd, customMarginBottom.toInt())
            binding.root.layoutParams = this
        }
        
        if (isShowAd) {
            binding.root.visible()
            binding.nativeAdView.visible()
        } else {
            binding.root.gone()
            binding.nativeAdView.gone()
        }
    }

    /**
     * ✅ 统一使用 NativeAdManager 加载原生广告
     */
    fun loadNativeAd(adTag: String) {
        reportEvent(adTag, "show_native_ad")
        
        // ✅ 优化：按场景（Tag）检查时间间隔
        if (NativeAdTimeUtil.isInterceptByTag(adTag)) {
            Log.d(TAG, "⏱️ Too soon for tag: $adTag, skipping")
            reportEvent(adTag, "no_native_ad", "interval_blocked")
            return
        }
        
        this.adTag = adTag
        val activity = context as? Activity
        
        if (activity == null || !activity.isValid()) {
            Log.w(TAG, "⚠️ Activity invalid, skipping ad")
            return
        }
        
        if (!isLoadAd) {
            Log.d(TAG, "⚠️ isLoadAd = false, skipping")
            return
        }
        
        // ✅ 统一使用 NativeAdManager 获取缓存广告
        val nativeAd = NativeAdManager.getInstance().getCachedAd(activity)
        
        if (nativeAd == null) {
            Log.d(TAG, "⚠️ No cached ad available for tag: $adTag")
            reportEvent(adTag, "no_native_ad", "no_cache")
            binding.root.gone()
            return
        }
        
        // ✅ 有缓存，立即展示
        Log.d(TAG, "✅ Displaying cached ad for tag: $adTag")
        inflateView(nativeAd)
        
        // ✅ 记录展示时间（按场景）
        NativeAdTimeUtil.saveTimeByTag(adTag, System.currentTimeMillis())
        reportEvent(adTag, "native_ad_shown", "success")
    }

    private fun inflateView(mNativeAd: NativeAd) {
        try {
            binding.root.visibility = View.VISIBLE
            binding.adMaxFl.visibility = View.GONE
            binding.nativeAdView.visibility = View.VISIBLE
            
            // Icon
            if (mNativeAd.icon != null) {
                binding.nativeAdIcon.setImageDrawable(mNativeAd.icon!!.drawable)
                binding.nativeAdIcon.visibility = View.VISIBLE
            } else {
                binding.nativeAdIcon.visibility = View.GONE
            }
            
            // Headline
            binding.nativeAdTitle.text = mNativeAd.headline
            
            // Body
            binding.nativeAdBody.text = mNativeAd.body
            
            // Media
            if (mNativeAd.mediaContent != null) {
                binding.coverview.mediaContent = mNativeAd.mediaContent
                binding.coverview.visibility = View.VISIBLE
            } else {
                binding.coverview.visibility = View.GONE
            }
            
            // Call to Action
            binding.cta.text = mNativeAd.callToAction
            
            // Bind views
            binding.nativeAdView.headlineView = binding.nativeAdTitle
            binding.nativeAdView.mediaView = binding.coverview
            binding.nativeAdView.bodyView = binding.nativeAdBody
            binding.nativeAdView.callToActionView = binding.cta
            binding.nativeAdView.iconView = binding.nativeAdIcon
            
            // Set native ad
            binding.nativeAdView.setNativeAd(mNativeAd)
            
            Log.d(TAG, "✅ Native ad inflated successfully")
        } catch (e: Exception) {
            Log.e(TAG, "❌ Failed to inflate native ad", e)
            binding.root.gone()
            reportEvent(adTag, "native_ad_error", e.message ?: "inflate_failed")
        }
    }
}

### B1. 升级 NativeAdTimeUtil 支持按场景拦截

**文件**: `quiz/src/main/java/com/quran/quranaudio/quiz/utils/NativeAdTimeUtil.kt`

**完整重写**:

```kotlin
package com.quran.quranaudio.quiz.utils

import android.util.Log
import com.quran.quranaudio.quiz.base.CloudManager

/**
 * ✅ 原生广告时间间隔管理器（按场景区分）
 * 
 * 优化：
 * 1. 按场景（Tag）独立计时，互不影响
 * 2. 默认间隔 5 分钟（可通过云端配置）
 * 3. 支持不同场景不同间隔
 */
object NativeAdTimeUtil {
    private const val TAG = "NativeAdTimeUtil"
    
    // ✅ 按场景存储上次展示时间
    private val showTimeMapByTag = hashMapOf<String, Long>()
    
    // ✅ 默认间隔时间：5 分钟
    private const val DEFAULT_INTERVAL_MS = 5 * 60 * 1000L  // 5 minutes
    
    /**
     * ✅ 按场景（Tag）检查是否应该拦截
     * 
     * @param tag 场景标识（如 "quiz_review_learn", "onboarding_language"）
     * @param customInterval 自定义间隔时间（毫秒），null 则使用云端配置或默认值
     * @return true 表示应该拦截，false 表示可以展示
     */
    fun isInterceptByTag(tag: String, customInterval: Long? = null): Boolean {
        // 获取间隔配置
        val intervalMs = customInterval 
            ?: CloudManager.getNativeIntervalTime()?.takeIf { it > 0 }
            ?: DEFAULT_INTERVAL_MS
        
        // 获取该场景的上次展示时间
        val lastTime = showTimeMapByTag[tag]
        
        if (lastTime == null) {
            // 第一次展示，不拦截
            Log.d(TAG, "✅ First show for tag: $tag")
            return false
        }
        
        // 计算时间间隔
        val elapsedTime = System.currentTimeMillis() - lastTime
        val shouldIntercept = elapsedTime < intervalMs
        
        if (shouldIntercept) {
            val remainingTime = (intervalMs - elapsedTime) / 1000  // seconds
            Log.d(TAG, "⏱️ Intercept tag: $tag (${remainingTime}s remaining)")
        } else {
            Log.d(TAG, "✅ Allow show for tag: $tag (${elapsedTime / 1000}s elapsed)")
        }
        
        return shouldIntercept
    }
    
    /**
     * ✅ 保存场景的展示时间
     */
    fun saveTimeByTag(tag: String, time: Long) {
        showTimeMapByTag[tag] = time
        Log.d(TAG, "💾 Saved show time for tag: $tag")
    }
    
    /**
     * ✅ 清除某个场景的时间记录（用于测试或重置）
     */
    fun clearTimeForTag(tag: String) {
        showTimeMapByTag.remove(tag)
        Log.d(TAG, "🗑️ Cleared time for tag: $tag")
    }
    
    /**
     * ✅ 清除所有时间记录
     */
    fun clearAllTimes() {
        showTimeMapByTag.clear()
        Log.d(TAG, "🗑️ Cleared all show times")
    }
    
    /**
     * ✅ 获取某个场景的上次展示时间
     */
    fun getLastShowTime(tag: String): Long? {
        return showTimeMapByTag[tag]
    }
    
    /**
     * ✅ 获取某个场景距离上次展示的时间（秒）
     */
    fun getElapsedTimeSinceLastShow(tag: String): Long? {
        val lastTime = showTimeMapByTag[tag] ?: return null
        return (System.currentTimeMillis() - lastTime) / 1000
    }
    
    // ⚠️ 保留旧方法以兼容现有代码，但标记为废弃
    @Deprecated(
        message = "Use isInterceptByTag() instead for better scene management",
        replaceWith = ReplaceWith("isInterceptByTag(functionTag)")
    )
    fun isIntercept(functionTag: String): Boolean {
        return isInterceptByTag(functionTag)
    }
    
    @Deprecated(
        message = "Use saveTimeByTag() instead",
        replaceWith = ReplaceWith("saveTimeByTag(functionTag, time)")
    )
    fun saveTime(functionTag: String, time: Long) {
        saveTimeByTag(functionTag, time)
    }
}
```

**关键改进**:
- ✅ 按场景（Tag）独立计时
- ✅ 默认间隔从可能的 24 小时改为 5 分钟
- ✅ 支持自定义间隔
- ✅ 添加详细日志和管理方法
- ✅ 向后兼容旧方法

if (nativeAd == null) {

    Log.d(TAG, "⚠️ No cached ad, hiding container")
    binding.root.gone()
    return
}

// ✅ 有缓存，立即展示
inflateView(nativeAd)
